SISTEM PENGELOLAAN JADWAL WORKOUT

# Penjelasan

>> Deskripsi Program
  Program ini adalah aplikasi CLI (command line) sederhana berbasis Python untuk mengelola jadwal latihan olahraga (workout) mingguan. Data disimpan sementara dalam list bersarang (list berisi list)

>> List yang saya pakai ada : hari, jenis_olahraga, durasi_menit, sets, reps, status
    Contoh : senin, push day/push up, 30 menit, 3 sets, 12 reps, belum

>> Program menyediakan menu berulang menggunakan (while) dengan pengoperasian penuh terhadap 4 data :

1. Tambah Jadwal Workout: Menambahkan data baru ke list
2. Lihat Semua Jadwal   : Menampilkan seluruh data dalam bentuk tabel  
3. Ubah Jadwal Workout  : Mengubah salah satu data berdasarkan nomor urut jadwal
4. Hapus Jadwal Workout : Menghapus salah satu data berdasarkan nomor urut jadwal
5. Keluar               : Berhenti Program (keluar dari while) / break

>> Materi yang saya terapkan yaitu :

1. Variabel, tipe data & operator — variabel list, str, int; operator perbandingan (==, <, >) dan logika pada validasi.
2. List & tuple — jadwal_workout sebagai list utama berisi list-list data (nested list).
3. Conditional statement (if/elif/else) — validasi menu, validasi input hari, validasi angka, validasi data kosong.
4. Looping (while, for) — menu utama berulang dengan while True, penelusuran data dengan for, serta validasi input berulang (while) supaya program tidak crash saat user salah input.
5. Algoritma & flowchart — alur program dirancang terlebih dahulu dalam bentuk flowchart sebelum ditulis kodenya (lihat bagian Flowchart).
